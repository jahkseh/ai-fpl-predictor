How It Works

Our prediction system uses historical FPL data and machine learning.

Historical Data

Previous gameweek performance, minutes, starts, goals, expected goals, expected assists and other relevant player statistics are used as model inputs.

Machine Learning

A Random Forest regression model analyses historical player performance to estimate expected FPL points.

Predictions

The model generates predicted points for players, allowing us to compare predicted performance with actual results.

Model Performance

Previous controlled walk-forward backtest: 2025/26 Gameweeks 11–38, using the four-season archive before expansion. The seven-season archive is being re-evaluated now.

Training data & validation

More data. Measured improvement.

The model is rebuilt from historical player records and evaluated against gameweeks it has not seen. We only report an accuracy change when the backtest or completed-gameweek results support it.
